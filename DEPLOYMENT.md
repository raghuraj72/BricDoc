# BricDoc Deployment Guide

This guide details how to deploy BricDoc publicly to **Vercel** (Frontend) and cloud platforms like **Render** or **Railway** (Backend).

---

## 1. Deploy Frontend to Vercel

### Option A: One-Click Deploy Link
Click the button below to deploy directly to your Vercel account:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fraghuraj72%2FBricDoc&root-directory=frontend&env=NEXT_PUBLIC_API_URL&envDescription=Backend%20API%20URL%20(e.g.%20https%3A%2F%2Fbricdoc-api.onrender.com%2Fapi%2Fv1%20or%20leave%20empty%20for%20local%20fallback))

### Option B: Step-by-Step Vercel Dashboard Import
1. Go to your Vercel Dashboard: [vercel.com/raghuraj-pratap-singh](https://vercel.com/raghuraj-pratap-singh)
2. Click **Add New...** > **Project**.
3. Select the GitHub repository: **`raghuraj72/BricDoc`**.
4. In **Project Configuration**:
   * **Root Directory**: Click **Edit** and choose `frontend`.
   * **Framework Preset**: Ensure **Next.js** is selected.
5. In **Environment Variables**:
   * Add `NEXT_PUBLIC_API_URL` (Value: your public backend API URL ending in `/api/v1`, e.g., `https://bricdoc-api.onrender.com/api/v1`).
6. Click **Deploy**.
   * Your site will be live within 1 minute at `https://bricdoc.vercel.app` (or your assigned Vercel URL).

## 2. Deploy Backend (FastAPI with PyMuPDF, OCR & Engines)

Because BricDoc performs document manipulation using C-optimized libraries (`PyMuPDF`, `Tesseract OCR`, `ReportLab`), the backend runs in a containerized environment.

### Deploy on Render (Free / Docker)
1. Go to [dashboard.render.com](https://dashboard.render.com/) and click **New +** > **Web Service**.
2. Connect your GitHub repository **`raghuraj72/BricDoc`**.
3. Render automatically detects the root [`render.yaml`](file:///c:/Users/RAGHURAJ%20P%20SINGH/OneDrive/Desktop/BricDoc/render.yaml) or choose:
   * **Runtime**: `Docker`
   * **Dockerfile Path**: `./backend/Dockerfile`
   * **Docker Build Context**: `./backend`
4. Set Environment Variables:
   * `SECRET_KEY`: A secure random string (auto-generated by Render)
   * `CORS_ORIGINS`: Your Vercel domain (e.g. `https://bricdoc.vercel.app`)
   * `GEMINI_API_KEY`: *(Optional)* Your Google Gemini API key for document AI.
5. Click **Create Web Service**. Render will assign a public HTTPS endpoint (e.g. `https://bricdoc-api.onrender.com`).

---

## 3. Connect Frontend to Backend

In your Vercel Project Settings:
1. Navigate to **Settings** > **Environment Variables**.
2. Set `NEXT_PUBLIC_API_URL` to `https://<your-backend-app>.onrender.com/api/v1`.
3. Trigger a redeploy (or push a commit).
4. All 20+ document tools, the interactive canvas editor, OCR, document vault, and AI workspace are live for the public!
